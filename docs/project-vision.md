# Project Vision

## Mission

Three-Eyed Raven is the central intelligence layer for a persistent Game of Thrones-inspired Valheim roleplay server. It should guide new players, preserve realm history, assist administrators, and eventually react to live server events from GameOps Bridge.

The bot should feel like a blend of the Three-Eyed Raven from Game of Thrones and the practical guidance of Hugin and Munin from Valheim: watchful, restrained, lore-aware, and useful.

## Product Promise

The Raven should help players understand the world without breaking immersion, help leaders administer the realm without repetitive manual work, and keep a trustworthy record of what happened across seasons, houses, wars, betrayals, milestones, and rulings.

## What This Is Not

- Not a novelty bot.
- Not a collection of random slash commands.
- Not an AI persona that speaks constantly.
- Not a replacement for the King or moderators.
- Not tightly coupled to any single game server integration.

## Long-Term North Star

The Raven should become the persistent memory and advisory presence of the realm:

- A guide for players.
- A chronicler of server history.
- A lore-aware narrator of important events.
- An assistant for server administration.
- A future consumer of GameOps Bridge events.

## Success Criteria

- Players can ask basic server questions and get accurate, concise answers.
- New players can learn rules, progression, houses, and roleplay expectations.
- Administrators can request reminders, announcements, summaries, and records.
- Major events become searchable history.
- Future live server data can be added without rewriting the bot.
